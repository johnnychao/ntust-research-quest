# 運動科學研究探險隊｜學生操作與繳交說明

對象是已修過基礎統計的研究生；不要求熟悉R。四堂各180分鐘，採教師帶領示範與個別闖關。你可以重試並更新反思，完成紀錄不應被當成沒有看過答案的正式測驗成績。

## 第一次使用

首頁有90秒課程介紹，可先按播放器的播放鍵，認識四堂課的任務。影片已附中文字幕，也提供可展開的文字稿和影片下載。手機需自行按播放，可使用播放器全螢幕；觀看不計入關卡完成紀錄。切換頁面、年度或模式會停止播放，再回首頁可重新觀看。

1. 在瀏覽器開啟課程首頁，確認開課年度與教材版本，選擇學生模式。
2. 選第1堂，依序完成六關。先閱讀摘要與來源，完成配對、排序或圖形探索，再回答核心題。
3. 答錯時閱讀提示、回到模型或摘要找理由，再重試；答對後閱讀解說並寫下一句反思，再進下一關。
4. 每堂結束時選「匯出進度」，儲存JSON到自己的裝置；選「列印學習成果」可透過瀏覽器列印視窗另存PDF。
5. 換裝置時選「匯入進度」並使用相同年度與教材版本。年度或教材版本不同會有獨立紀錄，不應覆蓋舊班成果。

同一年度闖關時，請只開一個本站分頁，避免舊分頁覆寫本機進度；來源閱讀頁可另開新分頁。換裝置前先匯出JSON，再到新裝置匯入。

進度只存在你的瀏覽器，不會自動送給教師。清除瀏覽器資料、使用無痕模式或換裝置都可能失去紀錄；定期匯出備份。若出現「無法儲存」提醒，先匯出進度再繼續。請勿把學生姓名、健康資料、研究受試者資料或其他機密寫入公開研究筆記。教師模式可跳關與看解說，適合示範；網站不提供考試防作弊功能。

## 讀懂這三種標籤

|標籤|意思|可如何使用|
|---|---|---|
|原來源摘要（source）|對章節或研究設計的自撰摘要|可引用原來源；不可把本站當作原始文章|
|概念示意（concept）|自編問題、公式或互動圖|用來解釋概念；滑桿不是從樣本估計SEM|
|合成練習（synthetic）|人工產生的練習資料及計算|可練方法；不可當成真實研究結果|

第5章量表示例與Gunnell等（2014）的成人兩波六個月SDT文章是不同來源。第6章是雪梨特定運動高中研究；PBC是知覺身體組成，不是BMI或體脂率。遊戲人物與對話是原創教學情境。

## R練習：在哪裡操作

1. 使用已安裝的R與RStudio。R是運算軟體；RStudio是方便編輯與執行R的介面。若未安裝，先依教師的實驗課說明完成安裝。
2. 從網站練習區或GitHub下載完整課程專案，保留labs與data資料夾相鄰。不要用原始研究逐筆資料取代合成檔。
3. 請下載完整GitHub專案，讓labs與data資料夾相鄰。Windows在解壓縮後的專案資料夾開啟PowerShell，執行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\labs\run_labs.ps1`；也可在終端機依序執行 `Rscript --vanilla labs/generate_data.R` 與 `Rscript --vanilla labs/analysis.R`。完整環境與路徑排錯依labs/README.md。
4. 如需在RStudio安裝缺少的套件，在Console輸入 `install.packages("lavaan")`。本次驗證使用R 4.5.2與lavaan 0.6-20；首次安裝需要網路。分析程式不會自動安裝。
5. 先查看資料維度、欄位、缺失與SYNTHETIC標記，再看模型結果；儲存完整輸出與執行資訊。
6. 網頁下載區的README及驗證結果是實際檔名與預期結果的依據。不要為了符合答案而改資料或填入未取得係數。

常見狀況：找不到資料時檢查完整下載與工作目錄；找不到套件時依README安裝指定套件；出現估計警告時保留完整訊息，核對資料與模型。未跑成功可繳診斷紀錄，不能把預先顯示結果假裝成自己的執行成果。

## 方法縮寫白話對照

|詞彙|白話說明|本課界線|
|---|---|---|
|FIML，全資訊最大概似法|用每人可取得的作答一起估計模型|沒有替每個缺失格找回真實值|
|MAR，在已觀察資訊條件下隨機缺失|控制已觀察資訊後，缺失不再依賴未觀察值的假設|不能由一個檢定保證成立|
|DIF，差異試題功能|控制共同因素後，某題仍因群組／共變項不同而有差異|本站R的MIMIC只估因素回歸，沒有檢驗DIF|
|robust，穩健修正|對某些分配偏離修正估計的不確定性或配適指標|仍有假設；不能與一般指標混算Δ|
|MLR，穩健最大概似估計|最大概似估計搭配穩健標準誤及檢定修正|本課連續合成指標採用；不直接保證適合所有序位問卷|

研究補給站實跑sport_cfa／sport_sem的自由度均為48，可練習整體配適判讀；自行畫的一因素三指標模型只用作藍圖，不以恰好識別模型的配適指標作驗證。原校園研究各波約半年；合成growth練習每波單位是一年，引用時要明示。

## 每堂課節奏

導入10分鐘 → 概念30分鐘 → 示範40分鐘 → 休息10分鐘 → 引導闖關40分鐘 → 獨立挑戰35分鐘 → 總結與作業15分鐘。每堂都有六關；課堂時間不足時，保留進度並在課後完成。

## 作業與繳交

由授課教師在課堂指定繳交平台及期限；網站不接收檔案。預設下次課前完成，第4堂由教師另訂期限。檔名採「課程年度_L堂次_學號_作業」；進度JSON可使用同一前綴。學號僅放在繳交檔名或私有平台，不放進公開網站。

### 作業1｜建立你的測量藍圖

1. 選一個運動、健康或教學構念；先界定內容，再提出3個原創指標。
2. 畫出一因素測量模型，標出因素、指標、負荷量、殘差及尺度設定。
3. 說明選用EFA或CFA的理由，列出模型估計前需檢查的資料條件。
4. 在研究補給站讀取已實跑的sport_cfa或sport_sem（四因素、300個合成個案、df＝48）輸出，寫一段整體配適、局部診斷與推論限制評語。自行畫的一因素三指標模型僅作測量藍圖，可能恰好識別，不能以其配適指標作有意義的模型檢驗。

繳交：

- 1–2頁PDF測量藍圖與指定正自由度合成模型評語，清楚區分兩者。
- 第1堂完成紀錄JSON；研究筆記每關至少一句。

評分規準（100分）：

|項目|配分|
|---|---:|
|構念界定與指標內容一致|30|
|模型圖、殘差與尺度設定正確|30|
|方法選擇與指定正自由度模型的診斷理由|25|
|來源、限制與表達可追溯|15|

### 作業2｜動機與活力的模型審查

1. 執行本站labs中的合成CFA／SEM練習，記錄實際使用資料、樣本數與缺失方法。
2. 挑一項負荷量或殘差診斷，用題目內容與統計證據共同評估候選修改。
3. 畫出測量及結構部分，寫出路徑估計和不確定性；若尚未成功執行，不得填寫未取得數字。
4. 分開介紹第5章示例與2014年SDT補充期刊，不宣稱合成資料重現原研究。

繳交：

- 2–3頁PDF審查報告。
- 使用的R腳本與完整文字輸出；未完成者附錯誤訊息與診斷步驟。
- 第2堂進度JSON。

評分規準（100分）：

|項目|配分|
|---|---:|
|資料身分與方法紀錄完整|25|
|題目審查兼具內容與統計理由|30|
|測量、結構與結果解讀正確|30|
|來源分離與推論界線清楚|15|

### 作業3｜可比較的量尺與缺失處理

1. 用本站合成恆等性練習或教師指定的示例表，列出各模型限制與比較目的。
2. 明示ΔCFI＝限制−較自由模型，逐項計算；搭配其他診斷，不以單一界值自動裁決。
3. 完成缺失處理表：缺失碼、缺失原因、候選方法、假設與需補資訊。
4. 畫四世代各四波的重疊設計，標出實測格與設計缺失格；不把elite當gender。

繳交：

- 2–3頁PDF，包括模型比較表、缺失處理表及世代圖。
- 若執行R，附腳本與完整輸出；若用概念示例，清楚標示概念示意。
- 第3堂進度JSON。

評分規準（100分）：

|項目|配分|
|---|---:|
|恆等性層次與比較目標一致|30|
|ΔCFI方向與診斷正確|25|
|缺失假設與處理透明|25|
|世代結構、欄位與來源正確|20|

### 作業4｜研究備忘錄與可重現交付

1. 執行本站合成成長練習，記錄時間原點、單位與截距／斜率定義。
2. 以圖或公式比較第一波及最後一波為零點的表達；解釋軌跡為何不應因正確重新參數化而改變。
3. 以一個MIMIC圖說明因素回歸與候選DIF，列出兩階段與聯合模型的差異。
4. 撰寫600–900字研究備忘錄：來源／設計、測量可比性、分析、結果、限制、下一步。

繳交：

- 研究備忘錄PDF與成長圖。
- R腳本、完整輸出及執行資訊；數字限填實際取得結果。
- 四堂完整進度JSON與網頁列印學習成果。

評分規準（100分）：

|項目|配分|
|---|---:|
|時間編碼與成長參數解讀|30|
|MIMIC與方法差異理解|25|
|結果可重現且未混用原研究數字|25|
|結論、限制與來源清楚|20|

## 自我檢查

- 所有估計值均來自實際保存的輸出；概念圖、原研究與合成結果各自標明。
- ΔCFI相減方向有寫出；elite不被當作gender，−9不被當實際分數。
- 成長模型有交代時間0與單位；未把兩階段練習宣稱為書中Mplus重現。
- 結論區分關聯、發展與因果，不用「顯著」代替效果大小與不確定性。
- 進度已匯出，PDF能讀，R輸出包含失敗或警告的必要資訊。
