# 合成教學資料字典

**全部資料都是 R 生成的合成資料，沒有真人、原研究個案或受保護問卷的題目文字。** 固定 seed＝1151011；值為連續指標，可能超出1–7，不應解釋為李克特量尺作答。文件與程式可公開，不能當作原研究重現證據。

| 檔案 | 單位與筆數 | 用途 |
|---|---|---|
| `synthetic_sport.csv` | 300個合成個案，一人一列 | EFA、CFA及運動動機→活力SEM |
| `synthetic_school_wide.csv` | 500個合成個案，一人一列、四波共12指標 | elite跨組／跨時間恆等性、MIMIC、簡化成長 |
| `synthetic_school_long.csv` | 2,000個「個案×波次」列，同一ID四列 | 教學展示寬表與長表，分析使用寬表 |

## 共用欄位

| 欄位 | 型態與定義 | 缺失／限制 |
|---|---|---|
| `id` | 字串，`SYN_S001`或`SYN_C001`形式 | 寬表唯一；長表與time組合唯一，不含識別真人資料 |
| `synthetic` | TRUE | 每列明確標示合成 |
| `age` | 整數，運動20–65；校園基線12–19 | 非真實年齡。長表為基線年齡加time |
| `baseline_age` | 長表專用，整數，基線年齡 | 不隨time改變 |
| `sex` | 合成二元教學標記0／1 | 不是elite；沒有對應真人性別，不推論任何現實族群 |
| `elite` | 合成運動身分：0＝一般組，1＝菁英組 | 與sex、cohort_group分開；恆等性跨組使用本欄 |
| `cohort_group` | 1／2，合成世代組 | 僅教學分組，並非原世代序列設計 |
| `time` | 0–3，距基線的年數 | 寬表共用欄time＝0；四波指標欄名帶time，運動僅基線 |
| `missingCode` | 常數-9，說明本檔缺失碼 | 本欄本身不是缺失觀測，不參與模型 |

## 運動指標

| 欄位 | 合成構念 | 使用方式 |
|---|---|---|
| `aut_1`–`aut_3` | 自主動機的三個連續合成指標 | 載入autonomy因素；不等同BREQ全部分量表 |
| `ctl_1`–`ctl_3` | 受控動機的三個連續合成指標 | 載入controlled因素 |
| `amo_1`–`amo_3` | 缺乏動機的三個連續合成指標 | 載入disengagement因素 |
| `vit_1`–`vit_3` | 活力的三個連續合成指標 | 載入vitality因素；不是SVS原題目 |

生成器使用三個相關動機因素與線性活力關係，加上隨機測量誤差；約4%指標儲存格隨機設為-9。SEM箭頭屬資料生成與模型設定，不是現實因果證據。

## 校園指標

`psc_t0_1`–`psc_t3_3`：四波（t0、t1、t2、t3），每波3個「身體自我概念」連續合成指標。長表對應欄為`psc_1`–`psc_3`。生成器使用共同負荷及截距、個案隨機截距與斜率、波次擾動，以及同題穩定方法成分；約5%指標儲存格隨機設為-9。跨時間模型允許同一指標跨波次殘差相關。這些是教學用生成假設，不是對原研究參數的估計。

## 缺失處理

- `read.csv(..., na.strings="-9")`將-9轉成NA。缺失碼欄不放進觀察變項。
- EFA：九個動機指標完整個案排除；實際有效N列於網頁JSON。
- CFA、SEM、恆等性及MIMIC：MLR估計、FIML處理指標缺失；共變項無缺失。
- 簡化成長：每波3題至少2題有效才算平均；不足2題該波為NA，再由FIML處理。這是明確教學規則，不是原量表計分規則。
- 未實作原研究多重插補，也未將多個插補檔的配適度或p值直接平均。
